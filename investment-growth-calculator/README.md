# Investment Growth Calculator

Calculates how much a historical investment in a selected public company would be worth today using historical market data.

## Features

- Downloads historical stock prices with yfinance
- Calculates shares purchased from an initial investment
- Computes final investment value, profit, and total return
- Visualizes the investment value over time

## Technologies

- Python
- pandas
- matplotlib
- yfinance

## Run

    python main.py

The ticker, investment amount, and date range can be modified directly in main.py.
