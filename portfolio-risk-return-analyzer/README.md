# Portfolio Risk & Return Analyzer

Analyzes the historical risk and return characteristics of a custom equity portfolio.

## Features

- Downloads historical market data
- Calculates cumulative and annualized returns
- Measures annualized volatility
- Calculates the Sharpe ratio
- Compares individual stocks with a custom portfolio
- Identifies the best and worst performing assets
- Visualizes portfolio performance over time

## Technologies

- Python
- NumPy
- pandas
- matplotlib
- yfinance

## Run

    python main.py

Tickers, portfolio weights, dates, and the risk-free rate can be modified directly in main.py.
