# Stock Comparison Dashboard

Compares historical market data across selected public companies.

## Features

- Downloads historical stock data with yfinance
- Compares multiple public companies
- Supports Open, High, Low, Close, and Volume data
- Visualizes historical market data with matplotlib

## Technologies

- Python
- pandas
- matplotlib
- yfinance

## Run

    python main.py

The selected companies, date range, and market data field can be modified directly in main.py.
